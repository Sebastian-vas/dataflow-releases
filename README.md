# Dataflow

Gestor de bases de datos del ecosistema Flowless: SQL y NoSQL, asistente Claude, diseño visual de
consultas, modelado, sincronización, tableros y trabajo en equipo.

Este repositorio solo publica los **instaladores**. Las apps instaladas se actualizan solas desde aquí.

## Descargar

Entra en [Releases](../../releases/latest) y elige tu sistema:

| Sistema | Archivo |
|---|---|
| Windows | `dataflow-*-win_x64.exe` (arm64: `win_arm64.exe`) |
| macOS | `dataflow-*-mac_universal.dmg` |
| Linux (Debian/Ubuntu/Mint) | `.deb` — `sudo apt install ./dataflow-*.deb` |
| Linux (cualquiera) | `.AppImage` (se actualiza sola) |

**Windows:** si SmartScreen avisa, pulsa «Más información» → «Ejecutar de todas formas».
**macOS:** la primera vez ábrela con clic derecho → *Abrir*.
